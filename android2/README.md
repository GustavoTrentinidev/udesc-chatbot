## Passo a passo para execução:

1. Clone o repositório
2. Execute os comandos:
```
 git checkout MOBILE
 ./run.sh
```
3. Importe o módulo android2/ na IDE Android Studio.
4. Execute e emule o módulo em um dispositivo virtual.
